Готовый статический тренажёр алгебры, геометрии и отдельного курса «Вероятность и статистика» для 7 класса. **128 тем, 18 модулей, 6 144 параметрических варианта заданий.** HTML/CSS и модульный JavaScript, без runtime-библиотек, регистрации и платных функций.

> **Начните с безопасности.** Если токен бота был отправлен в переписку, отзовите его в @BotFather и получите новый. В проекте нет настоящих ключей. Telegram по умолчанию выключен. GitHub Secrets → публичный `config.js` **не скрывает токен**: прямой режим требует явного согласия с этим риском. Прилагается более безопасный для токена Worker-прокси.

## Что уже работает

- Тетрадный интерфейс: клетка, поля, крупные кнопки, адаптация под телефон и компьютер.
- Каталог модулей; поиск по теме и УМК; фильтры предмета и уровня.
- В каждом уроке: **памятка, КР на 8 заданий, ДЗ на 8 других заданий**, свободная практика на 12 заданий.
- 48 вариантов на тему: **16 наборов параметров × 3 формы упражнения**. Это варианты, а не 48 разных сюжетов. В банк включены решения и подсказки.
- Числа, обыкновенные/десятичные/смешанные дроби, выражения, пары координат, списки, выбор ответа, короткий текст, порядок шагов.
- Проверка сразу после нажатия «Проверить» или Enter; зелёный/красный ответ, подсказки и разбор.
- Имя или псевдоним в localStorage, черновик, возобновление, активное время, прогресс и история 200 последних работ.
- Баллы по **первой математически оформленной попытке**. Исправлять можно; ошибка формата не считается попыткой. Пропуски — без балла.
- Настраиваемые пороги «5/4/3» — по умолчанию 85/70/50%. Это учебная шкала, **не обязательная шкала ФГОС**.
- Итоговый разбор, TXT/JSON полного отчёта, CSV статистики и печать. Ссылка на фиксированный вариант ДЗ.
- Telegram: отдельное согласие на конкретную работу, предпросмотр, ручная отправка и тест связи. Успех — только при подтверждённом `message_id`. Автоповторов нет.
- Опциональный Cloudflare Worker: секрет остаётся на серверной стороне, получатель фиксирован; включён Turnstile, проверяется Origin, размер и схема отчёта. Ограничитель IP в памяти — best effort.

**Полное доказательство и чертёж не оцениваются сравнением строк.** Здесь проверяются вычисления, выбор и порядок готовых шагов. Свободный текст обоснования до 1200 символов включается в полный отчёт для учителя без автоматического балла.

## Запустить локально

Нужны Python 3 и современный браузер. Node для обычного просмотра не нужен.

```bash
cd matematika7
python3 -m http.server 3000 --bind 0.0.0.0 --directory site
```

Откройте `http://localhost:3000`. На Windows обычно используется команда `py -m http.server 3000 --directory site`.

**Не открывайте `index.html` двойным щелчком:** ES-модулям нужен HTTP(S). При публикации на Pages всё работает и в подкаталоге репозитория; маршруты имеют вид `#/lesson/a11`.

## Самая короткая публикация без Telegram

1. Создайте **публичный** репозиторий GitHub с веткой `main`.
2. Загрузите **содержимое этой папки**, включая скрытую `.github/workflows/deploy.yml`, в корень репозитория. В корне должны оказаться `package.json`, `site/`, `.github/`, а не ещё одна внешняя папка.
3. **Settings → Pages → Source → GitHub Actions.**
4. **Actions → «Проверить и опубликовать Тетрадь 7» → Run workflow**, ветка `main`, либо выполните push в `main`.
5. После зелёных `check → build → deploy` адрес появится в Pages и в окружении `github-pages`.

Без Secrets тренажёр работает полностью, кроме Telegram. Не надо коммитить `_public/` или `node_modules/`.

### Подключение Telegram: два режима

| Режим | GitHub Actions Variables | Где находятся секреты |
|---|---|---|
| Выключен | ничего, либо `TELEGRAM_MODE=off` | не используются |
| **Рекомендуемый для рабочего бота:** proxy | `TELEGRAM_MODE=proxy`, `TELEGRAM_PROXY_URL`, `TURNSTILE_SITE_KEY` | только в Secrets Cloudflare Worker |
| **Небезопасный прямой:** direct | `TELEGRAM_MODE=direct`, `ALLOW_UNSAFE_DIRECT=true` | GitHub Secrets при сборке; **после публикации токен виден всем в JS** |

Для direct создайте GitHub **Repository Secrets** `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Для proxy те же имена задаются в Worker Secrets, плюс `TURNSTILE_SECRET_KEY`. Ключ Turnstile для сайта публичен, secret key — нет. [Полная пошаговая инструкция](docs/DEPLOY.md).

Токен Telegram невозможно ограничить только одним `chat_id` или одним методом `sendMessage`. Права бота в группе этого не исправляют. Отдельный малоценный бот уменьшает ущерб, но не защищает опубликованный ключ.

## Проверить и собрать

Для разработки: Node.js ≥20, npm, Python 3. В CI используется Node 22.

```bash
npm ci
npm run check:secrets
npm test
npx playwright install --with-deps chromium
npm run test:e2e
npm run build
```

Сборка создаст `_public/`; исходный `site/config.js` не меняется. По умолчанию режим `off`. Публикуется только статика из `_public/`. Скрипт подстановки не выводит значения ключей в лог.

Дополнительная математическая проверка независимой библиотекой:

```bash
python3 -m pip install -r requirements-dev.txt
python3 scripts/verify_math.py
python3 scripts/verify_complex.py
```

Выполнено при подготовке: **43/43 unit/integration-тестов, 11/11 сценариев Chromium, 0 ошибок консоли**; канонические ответы и альтернативы всех 6 144 заданий проходят checker. Дополнительно: 880 выражений восстановлены из условий и проверены SymPy, 96 числовых выражений, 96 линейных уравнений, 992 геометрических/статистических эталона — без расхождений. Это не экспертная сертификация каждого доказательства. Реальная доставка в ваш бот проверяется отдельно после настройки нового токена.

```text
│           ├── app.js           # маршруты, экраны, обработчики

│           ├── bank*.js         # генераторы и детерминированные работы
│           ├── checker.js       # безопасный точный математический парсер
│           ├── session.js       # попытки, баллы, отчёты
│           ├── storage.js       # localStorage и fallback в памяти
│           ├── telegram.js      # fetch, тайм-ауты и ошибки
│           ├── report-message.js # экранирование, текст Telegram
│           ├── challenge.js     # опциональная загрузка Turnstile
│           ├── diagrams.js      # геометрия/графики/диаграммы, inline SVG
│           └── ui.js            # компоненты, модальные окна, иконки
├── worker/                      # опциональный серверless-прокси
├── scripts/                     # build, секрет-сканер, chat_id, экспорты
├── tests/                       # unit/integration и браузерные проверки
├── docs/                        # программа и инструкции
├── package.json / package-lock.json
└── LICENSE                      # MIT; шрифты — отдельная OFL
```

**Важные границы:** нет авторизации и синхронизации между устройствами; ученик способен изменить клиентские баллы; история зависит от браузера. Ссылки на ДЗ не создают серверный журнал назначений. Данные детей и отправка в Telegram требуют согласований и политики школы. Доступность GitHub, Cloudflare и Telegram зависит от сети и региона; полный отчёт можно скачать без отправки.

Проект не связан с автором сайта-примера и авторами учебников. Код, оформление и параметрические задания подготовлены заново; названия УМК служат для тематического сопоставления.
