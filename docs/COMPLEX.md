# Сложная комплексная практика · версия 1.1

**[Открыть раздел на сайте](https://baikovaalina.github.io/tetrad-7/#/challenge)**

Добавлены **24 темы, 3 модуля, 1 152 параметрических варианта**. Из них 16 алгебраических тем (768 вариантов) и 8 геометрических (384). Это 16 наборов параметров × 3 формы на тему, а не 1 152 принципиально разных метода решения. Исходные 104 урока и их ID сохранены; всего теперь **128 тем / 18 модулей / 6 144 варианта**.

## Как устроено усложнение

- В одном условии связаны несколько действий: составление модели → преобразование → решение → следующий расчёт → проверка.
- В составном числовом ответе требуется 2–4 результата. Ввод через `;`, порядок указан в условии. За весь правильный ответ 1 балл, частичного оценивания нет. Наборы корней, напротив, принимаются в любом порядке без повторов.
- Вынесены ловушки: потерянный корень при делении на выражение; забытая ОДЗ; нерассмотренный параметр; смена базы процента; исключение вырожденного треугольника; неверный отсчёт времени.
- У каждого задания свой разбор, обычно четыре шага, у составных доказательств пять–шесть. После математической попытки можно открыть решение. В конце разборы доступны в отчёте и TXT/JSON.
- Своё обоснование можно написать и для алгебры, и для геометрии. Текст проверяет учитель; автоматически он баллы не добавляет.
- КР и ДЗ остаются по 8 заданий, практика — 12. Сложная работа может занимать существенно больше времени, чем базовая; жёсткого таймера нет. Учитель может предложить решить часть заданий, но автоматическая оценка полной работы учитывает все 8.

## Три реальных примера из банка

### A70 · смесь и последующее разбавление

Из 10%-го и 25%-го растворов приготовили **20 кг 16%-го раствора**, затем добавили **4 кг воды**. Требуется масса каждого исходного раствора и конечная концентрация.

1. `x + y = 20`.
2. `x/10 + y/4 = 16/5` — масса соли.
3. Решение: `x = 12`, `y = 8`.
4. После воды соли по-прежнему `16/5` кг, общая масса 24 кг; концентрация `40/3` процента.

Ответ: **`12; 8; 40/3`**. Вариант: `a70-01`.

### A74 · система задаёт второе уравнение

Решить `x + y = 10`, `2x − y = −1`, затем с найденными x, y решить `(t − x)² = y²`.

1. Сложение даёт `3x = 9`, `x = 3`.
2. `y = 7`.
3. `t − 3 = ±7`.
4. Корни `−4` и `10`.

Ответ по порядку: **`3; 7; −4; 10`**. Вариант: `a74-01`.

### G40 · внутренняя и внешняя биссектрисы

В треугольнике `A = 44°`, `B − C = 20°`. Внутренние биссектрисы B и C пересекаются в I. Найти A, B, C, BIC.

1. `B + C = 136°`.
2. Вместе с разностью это даёт `B = 78°`, `C = 58°`.
3. В треугольнике BIC углы при B и C равны `B/2` и `C/2`.
4. `BIC = 180° − 39° − 29° = 112°`.

Ответ: **`44; 78; 58; 112`**. Вариант: `g40-01`.

## Отношение к пособиям и проверке

Для алгебры Галицкий–Гольдман–Звавич служит **тематическим ориентиром**: комбинирование преобразований, уравнения, системы, моделирование и развитие рассуждений. Подтверждённый библиографический ориентир — сборник для 8–9 классов с повторением и углублением материала 7 класса. Это не заявление, что весь материал 8–9 классов входит в программу 7-го, и не подтверждение неизвестного конкретного издания «7–9». Тексты и решения составлены заново; номера чужих упражнений не используются.

Геометрические темы ориентируются на сочетание теорем Атанасяна и задачи подходящих разделов Гордина, **не приписываются Галицкому**. Для решения не требуется Пифагор, хотя при dev-аудите он используется для независимой проверки существования специально подобранных конфигураций длин.

`verify_complex.py` независимо от браузерного checker проверяет **1 104 математические модели**, включая полный набор корней, исходную ОДЗ, особые параметры, перебор целых решений и второй этап задачи. **80 конфигураций длин** проверены на геометрическую возможность. Ещё **48 доказательств** проходят лишь структурную проверку шагов; это не их машинная сертификация. Методический просмотр учителем по-прежнему необходим.

Telegram в этой версии оставлен выключенным по выбранному пользователем варианту «Сейчас только сложные задачи». Настройки и протокол не менялись.
