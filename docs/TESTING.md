## Повторить основную проверку

```bash
npm ci
npm run check:secrets
npm test
npx playwright install --with-deps chromium
npm run test:e2e
npm run build
```

На системе без прав установки OS-пакетов зависимости Chromium устанавливаются отдельно администратором. Обычному ученику это не требуется — только разработчику/CI. После `npm ci` убедитесь, что lockfile не был самопроизвольно изменён.

E2E запускает собственный временный HTTP-сервер на свободном локальном порту и закрывает его/браузер в конце. Настоящие ключи и внешний Telegram не нужны. Артефакты появляются в `test-results/` (не коммитятся): снимки desktop/mobile, `e2e-summary.json`, а при отказе — `failure.png` и текст ошибки.

## Что проверяют unit/integration

- `checker.test.js`: точная дробная арифметика, запятая, Unicode, смешанные числа, порядок действий, альтернативы, ОДЗ с несколькими переменными, формы, списки/пары/порядок и ограничения парсера. Некорректный ввод не исполняется.
- `bank.test.js`: все темы и памятки, все 48 вариантов/тему и объявленные альтернативы, уникальность полных заданий, стабильные ID, структура SVG, КР/ДЗ, независимые примеры и геометрические/статистические инварианты.
- `session.test.js`: первая попытка/исправление, формат, пропуски, завершение, пороги, время/отчёт и свободное обоснование без балла.
- `storage.test.js`: профиль/черновик/настройки, 200 работ, повреждённые записи, запрещённое хранилище.
- `telegram.test.js`: off без сети, gate direct, HTML-экранирование/лимит, URLSearchParams, режим proxy, номера сообщений, ошибки 400/401/403/429, не-JSON/обрыв/тайм-аут, отсутствие автоповторов и утечки токена в исключении.
- `worker.test.js`: фиксированный получатель, только сокращённый ответ, Origin/метод/MIME, схема/размер, hostname/action Turnstile, best-effort лимит, неопределённая доставка.
- `build.test.js`: off по умолчанию, отказ неразрешённого direct, подстановка только в копию, неизменность источника, отсутствие ключа в логе, proxy и ошибочные параметры.

## Браузерные сценарии

1. Каталог, предмет/уровень/поиск, сохранение фильтров, пустой результат и сброс.

6. Все 104 страницы уроков, основные разделы, изменение учебных порогов.

8. Повреждённое и заблокированное localStorage.
9. Клиентский proxy с имитацией сервиса: без согласия кнопка выключена, один запрос, подтверждение, локальная блокировка после успеха и reload.

## Независимая математическая проверка

```bash
python3 -m pip install sympy
python3 scripts/verify_math.py
```

SymPy — только дополнительный dev-инструмент; не зависимость сайта. Скрипт читает **авторский банк**, восстанавливает выражения из условий, сравнивает их с ответами, независимо решает выбранные линейные уравнения, проверяет ряд геометрических и статистических моделей. Не принимает пользовательские строки и не должен становиться HTTP endpoint. Для новых форм условий его нужно дополнять.

Ожидаемый результат текущей версии:

```json
{
  "symbolic_from_prompts": 832,
  "numeric_from_prompts": 96,
  "linear_equations": 96,
  "independent_geometry_statistics": 992,
  "errors": 0
}
```

## Ручная приёмка учителем перед уроком

- [ ] Сверить перечень/уровни со своей действующей программой и нужными изданиями УМК.
- [ ] Выборочно решить задачи каждого используемого урока; проверить объяснения и применимость способа.
- [ ] Показать ученикам запись дробей/координат/степеней и правило первой попытки.
- [ ] На рабочем телефоне проверить клавиатуру, кнопки и доступность GitHub.
- [ ] Настроить локальные пороги оценок или общую конфигурацию; помнить, что старые сессии хранят прежние пороги.
- [ ] Пройти `/start`, тест связи, одно настоящее ДЗ и проверить правильный чат Telegram.
- [ ] Убедиться, что в режиме proxy браузер не содержит токена, а Turnstile настроен на реальный hostname.
- [ ] Согласовать псевдонимы, передачу данных и хранение результатов со школой.
- [ ] Предусмотреть альтернативу при блокировке сети: скачиваемый TXT/JSON.

Браузерная регрессия проведена в Chromium, не на реальном iPhone/Android и не во всех версиях Safari/Firefox. Проверка автоматического SVG не заменяет визуальный/методический просмотр каждого чертежа.
